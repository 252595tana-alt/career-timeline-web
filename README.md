## 開き方・編集

`index.html` を Chrome / Edge などのブラウザで開きます。このファイルだけで表示・編集できます。サーバー、インストール、外部通信は不要です。

「文字を編集」を押して、変更したい文字をクリックします。見出し・本文・会社名・年次を含む46個のテキスト枠が編集対象です。「編集を終了」で閲覧へ戻ります。

「HTMLを保存」を押すと、その時点の編集内容を含む単体HTMLを保存します。受け渡し・保管にはこのファイルを使用してください。元のPowerPointは変更されません。

ブラウザがlocalStorageを許可する環境では、変更をそのブラウザ内に自動保存します。保存が許可されない環境では画面下部に案内が出ます。自動保存は端末・ブラウザ・ファイル／URLごとで、他の端末や公開サイトには反映されません。確実な保管には「HTMLを保存」を使用してください。

文字を増やして元の枠を超えた場合、編集中に注意を表示します。勝手な要約・ページ追加・配置変更は行いません。文字量や改行を調整してください。

「元資料の文章に戻す」は確認後、全46枠を添付PowerPointの表示内容へ戻します。

## 表示・印刷

- 元と同じ1ページ、16:9（1280 × 720）です。
- 添付「Design Temp_Web_Template.html」の1ページ目の背景（右上の淡い青・左下の淡いピンク・薄いグリッド）と右下ページ表示を使用しています。元資料と同じ1ページのみです。
- 背景は元SVGを16:9に合わせて描画し、画素を変更しないロスレスWebPへ変換。文字・図形は画像化せず、従来どおり編集できます。グリッドはテンプレートと同じCSSです。
- 右下は「1 / 1」です。1ページだけなので「戻る」「次へ」は表示しません。
- 全体表示は画面に合わせた縮尺表示です。スマートフォンで文字を拡大する場合は「100％」「150％」を選び、スクロールします。レイアウトの縦並びへの組み替えは行いません。
- 「全画面」「印刷」に対応します。印刷は16:9横、余白なし、背景のグラフィックを有効、ヘッダー・フッターを無効にしてください。
- 端末にインストールされているフォントを使います。フォントファイルは同梱しません。フォント環境により文字の見え方には差が生じます。

## 内容の扱い

表示されているスライド本文を基準に変換しました。年次、会社名、順序、文章は補足・修正していません。元資料の表示上のテキスト46枠について、文字列の一致を確認しています。

表示されない発表者ノート、旧版の説明、面接メモなどはHTMLに含めていません。元PowerPoint自体もこのZIPには含めていません。

## ソース構成

- `index.html`：CSS・JavaScript・背景画像を内包した完成版。
- `shell.html`：HTML編集元。内容や配置を変更する場合はこちらを編集。
- `styles.css`：元スライドの寸法、文字・図形の表示、共通背景、操作バー、印刷設定。
- `script.js`：文字編集、ブラウザ内保存、編集済みHTML出力、倍率、ページ操作。
- `assets/background-cover.webp`：添付テンプレートの1ページ目から書き出したロスレス背景。
- `build.py`：編集元から単体HTMLを生成。Python 3で `python build.py` を実行。
- `validation.json`：照合・表示・編集・保存テストの結果と検証範囲。
- `.nojekyll`：静的ファイル用。
- `robots.txt`：クロール抑制の指定。認証・アクセス制限ではありません。

## 公開・更新

GitHub Pages用の資料です。認証・パスワード保護はありません。URLを知る人は閲覧できます。

公開中の文章を更新するには、ブラウザで「HTMLを保存」したファイルを `index.html` に改名して、GitHubのmainブランチへ反映してください。再デプロイ後に公開URLも更新されます。コードから再ビルドする運用では、編集結果を `shell.html` にも反映してください。

このブラウザ内への自動保存やHTMLのダウンロードだけでは、他の人が見る公開資料は変わりません。
